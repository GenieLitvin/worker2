# TypeScript Node.js Project

Этот проект демонстрирует различные типы функций в TypeScript.

## Установка

```bash
npm install
```

## Запуск

Для запуска проекта в режиме разработки:
```bash
npm start
```

Для компиляции TypeScript в JavaScript:
```bash
npm run build
```

## Структура проекта

- `src/index.ts` - основной файл с примерами функций
- `tsconfig.json` - конфигурация TypeScript
- `package.json` - зависимости и скрипты проекта

## Примеры функций

В проекте представлены следующие типы функций:
1. Простая функция
2. Стрелочная функция
3. Функция с опциональными параметрами
4. Функция с параметрами по умолчанию
5. Функция с rest параметрами
